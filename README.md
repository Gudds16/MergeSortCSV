# Merge Sort using Java

## Description

This project implements the **Merge Sort** algorithm in Java to sort a CSV dataset based on the **OrderID** column.

## Features

- Reads data from a CSV file
- Sorts records using Merge Sort
- Displays the sorted data in ascending order

## Files

- `MergeSortCSV.java` - Java source code
- `orders.csv` - Dataset used for sorting
- `README.md` - Project documentation

## How to Run

Compile the program:

```bash
javac MergeSortCSV.java
```

Run the program:

```bash
java MergeSortCSV
```

## Algorithm

- Divide the array into two halves.
- Recursively sort each half.
- Merge the sorted halves.

**Time Complexity:** `O(n log n)`

**Space Complexity:** `O(n)`
